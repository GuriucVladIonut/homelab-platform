# ADR-0001 - Use k3s

## Status

Accepted.

## Context

The initial homelab is a single-node laptop environment with constrained resources and frequent shutdown/startup cycles.

## Decision

Use k3s as the Kubernetes distribution.

## Consequences

Advantages:

- low operational overhead
- Kubernetes-compatible API
- good fit for a single node
- future cluster expansion remains possible

Trade-offs:

- Kubernetes complexity still exists
- single physical node remains a single point of failure
